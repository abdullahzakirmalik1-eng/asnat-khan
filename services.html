QUESTIONS

Before You Choose.

Clear answers to help you choose the right package with confidence.

What is included in the Basic package? ▼

The Basic package ($50) includes a complete basic business website with up to 5 pages, free hosting, domain setup (domain provided by client), written content, relevant images, frontend and backend implementation, speed optimization, and SEO foundation. It is designed to give basic business websites everything required to get online.

What is included in the Standard package? ▼

The Standard package ($100) includes up to 7 pages and includes everything in the Basic package (free hosting, client-provided domain setup, content, images, frontend, backend, speed optimization, and SEO) plus integrated payment functionality built directly into the website experience.

What is included in the E-Commerce package? ▼

The E-Commerce package ($200) provides a complete e-commerce website with up to 8 pages and 10 e-commerce products included. It incorporates everything included in Basic (free hosting, client-provided domain setup, content, images, code, speed, and SEO) together with payment functionality so you are ready to sell online.

Can I add more products to the E-Commerce package? ▼

Yes. Additional e-commerce products are $1 per product.

Do the packages include SEO and speed optimization? ▼

Yes. SEO and speed optimization are included in the website packages as specified above.

Do you provide the domain and hosting? ▼

You provide the domain name you want to use. We provide free hosting for the website as part of the package. We can also help with the domain setup and connection.

Can I request something outside these packages? ▼

Yes. If your project has requirements outside the listed packages, you can share the details when starting the project so the right scope can be discussed.
